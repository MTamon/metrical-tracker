# Metrical Photometric Tracker requirements for
# CUDA 12.8 / PyTorch 2.9.1 / Python 3.11.
#
# This file is aligned with:
#   - MTamon/smirk            (release/cuda128)
#   - MTamon/DECA             (cuda128)
#   - MTamon/FlashAvatar      (release/cuda128-fixed)
# so that metrical-tracker can coexist with those projects in the same
# environment.
#
# The authoritative installation path is install_128.sh (alongside this file),
# which installs the pin set with `--no-deps` to guarantee exact versions and
# then builds pytorch3d from source against torch 2.9.1 + CUDA 12.8.
# This requirements.txt exists for reference and for simple
# `pip install -r requirements.txt` usage in already-pinned environments.
#
# NOTE 1: chumpy must be installed from GitHub main (numpy 2.x compatible):
#         pip install git+https://github.com/mattloper/chumpy.git
#         (same source as smirk/DECA/FlashAvatar). It is intentionally NOT
#         listed below because pip cannot reliably express a git URL alongside
#         `==` pins across tooling.
#
# NOTE 2: pytorch3d 0.7.8 must be built from source for this torch/CUDA combo.
#         See install_128.sh for the exact invocation.
